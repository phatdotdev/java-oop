# Java Packages *(Gói trong Java)*

**Last Updated:** 29 Sep, 2026 *(Cập nhật lần cuối: 29/09/2026)*

A **package** in Java is used to group related classes, interfaces, enums, and sub-packages. Packages help organize code, avoid naming conflicts, control access, and make large applications easier to maintain.

> **Giải thích:** **Package (Gói)** trong Java được dùng để gom nhóm các `class`, `interface`, `enum` và các gói con (`sub-packages`) có liên quan lại với nhau. Package giúp tổ chức mã nguồn gọn gàng, tránh xung đột trùng tên lớp, kiểm soát quyền truy cập và giúp các ứng dụng lớn dễ bảo trì hơn.

* **A package can contain classes, interfaces, enums, and sub-packages.** *(Một package có thể chứa các lớp, giao diện, kiểu liệt kê và các package con.)*
* **The `package` statement defines the package of a source file.** *(Câu lệnh `package` xác định gói mà tệp mã nguồn đó thuộc về.)*
* **They make code easier to maintain and reuse.** *(Giúp mã nguồn dễ bảo trì và tái sử dụng hơn.)*

---

## Types of Java Packages *(Các loại Package trong Java)*

Java packages are mainly divided into two types *(Các gói trong Java được chia thành 2 loại chính)*:

### 1. Built-in Packages *(Package có sẵn của Java)*

Built-in Packages are packages provided by the Java API. They contain classes and interfaces for common programming tasks. Some of the commonly used built-in packages are:
*(Là các gói được bộ thư viện Java API cung cấp sẵn, chứa các lớp và giao diện phục vụ các tác vụ lập trình phổ biến. Một số gói thông dụng nhất gồm:)*

* **`java.lang`:** Contains fundamental classes and interfaces that support core Java functionality, such as `Object`, `String`, `Math`, `System`, and wrapper classes like `Integer`, `Double`, and `Boolean`. **This package is automatically imported.** *(Chứa các lớp cốt lõi hỗ trợ nền tảng Java như `Object`, `String`, `Math`, `System` và các lớp bao như `Integer`, `Double`, `Boolean`. **Gói này được tự động import mặc định.**)*
* **`java.io`:** Contains classes for supporting input/output operations. *(Chứa các lớp hỗ trợ các thao tác nhập/xuất dữ liệu, đọc ghi file.)*
* **`java.util`:** Contains utility classes that implement data structures such as Linked Lists and Dictionaries (Map), as well as support for date and time operations. *(Chứa các lớp tiện ích triển khai cấu trúc dữ liệu như `ArrayList`, `LinkedList`, `HashMap`, cùng các công cụ xử lý ngày giờ, ngẫu nhiên...)*
* **`java.awt`:** Contains classes for implementing the components for graphical user interfaces (like buttons, menus, etc). *(Chứa các lớp xây dựng thành phần giao diện đồ họa người dùng như nút bấm, menu...)*

#### Example: Using `java.util.Random` *(Ví dụ: Sử dụng lớp `Random` từ gói có sẵn)*

```java
import java.util.Random; // built-in package (import gói có sẵn)

public class GFG {
    public static void main(String[] args) {
        // Using Random class (Sử dụng lớp Random)
        Random rand = new Random();   

        // Generates a number between 0–99 (Sinh số nguyên ngẫu nhiên từ 0 đến 99)
        int number = rand.nextInt(100);  

        System.out.println("Random number: " + number);
    }
}
```

**Output *(Kết quả)*:**
```text
Random number: 59
```

**Explanation *(Giải thích)*:** The program imports the `Random` class from the `java.util` package. The `nextInt(100)` method generates a random integer from `0` to `99`. *(Chương trình import lớp `Random` từ gói `java.util` và gọi `nextInt(100)` để tạo một số nguyên ngẫu nhiên trong khoảng từ `0` đến `99`.)*

### 2. User-defined Packages *(Package do người dùng tự định nghĩa)*

User-defined Packages are packages created by programmers to organize application-specific classes and interfaces.
*(Là các gói do lập trình viên tự tạo ra để phân chia và tổ chức các lớp, giao diện theo từng chức năng riêng của ứng dụng.)*

**File 1: `com/myapp/Helper.java`**
```java
package com.myapp;

public class Helper {
    public static void show() {
        System.out.println("Hello from Helper!");
    }
}
```

**File 2: `Test.java` *(Sử dụng lớp `Helper` ở một file khác)***
```java
import com.myapp.Helper;

public class Test {
    public static void main(String[] args) {
        Helper.show();
    }
}
```

**Explanation *(Giải thích)*:** The `Helper` class belongs to the `com.myapp` package. The `Test` class imports it using the `import` statement and calls its static `show()` method. *(Lớp `Helper` thuộc gói `com.myapp`. Lớp `Test` nạp lớp này thông qua câu lệnh `import` và gọi phương thức tĩnh `show()` của nó.)*

## Package Declaration & Folder Structure *(Khai báo Package & Cấu trúc thư mục)*

### Package Declaration *(Khai báo Package)*
The `package` statement is used to specify the package to which a class belongs. It must be the **very first line** of the `.java` file (excluding comments).
*(Câu lệnh `package` dùng để chỉ định gói mà lớp thuộc về và bắt buộc phải nằm ở **dòng đầu tiên** của file `.java`).*

**Syntax *(Cú pháp)*:**
```java
package packageName;
```

### Folder Structure *(Cấu trúc thư mục)*
The directory structure normally follows the package name. *(Cấu trúc thư mục trên ổ cứng phải khớp tương ứng với tên phân cấp của package).*

```text
src/
 └── com/
      └── myapp/
           └── Helper.java   <-- Đầu file khai báo: package com.myapp;
```

## Accessing Classes Inside a Package *(Cách truy cập các lớp bên trong một Package)*

In Java, we can import classes from a package using either of the following methods *(Ta có thể truy cập lớp từ package khác bằng các cách sau)*:

1. **Import a Single Class *(Import một lớp cụ thể — Khuyên dùng)*:**
   ```java
   import java.util.Vector;
   ```
   *This imports only the `Vector` class from the `java.util` package. (Chỉ nạp duy nhất lớp `Vector` từ gói `java.util`.)*

2. **Import all classes from a package *(Import toàn bộ lớp trong một gói)*:**
   ```java
   import java.util.*;
   ```
   *This imports all classes and interfaces from the `java.util` package **but does not include sub-packages**. (Nạp toàn bộ các lớp và interface nằm trực tiếp trong `java.util`, **không bao gồm các gói con** bên trong nó như `java.util.concurrent`.)*

3. **Use Fully Qualified Name *(Dùng tên đầy đủ kèm package — Không cần `import`)*:**
   ```java
   java.util.ArrayList list = new java.util.ArrayList();
   ```

#### Example: Import vs Fully Qualified Name *(Ví dụ minh họa)*

```java
import java.util.Vector;

public class Geeks {
    public Geeks() {
        // java.util.Vector is imported, we are able to access it directly in our code.
        // (Vector đã được import nên có thể gọi trực tiếp tên lớp)
        Vector v = new Vector();

        // Accessing ArrayList using its fully qualified name without importing
        // (Gọi ArrayList bằng tên đầy đủ kèm đường dẫn package mà không cần dòng import)
        java.util.ArrayList l = new java.util.ArrayList();
        l.add(3);
        l.add(5);
        l.add(7);
        
        System.out.println(l);
    }

    public static void main(String[] args) {
        new Geeks();
    }
}
```

**Output *(Kết quả)*:**
```text
[3, 5, 7]
```

**Explanation *(Giải thích)*:** `Vector` is accessed directly because it is imported. `ArrayList` is accessed using its fully qualified name, `java.util.ArrayList`. *(`Vector` được dùng trực tiếp nhờ câu lệnh `import`, còn `ArrayList` được gọi thông qua tên đầy đủ `java.util.ArrayList`.)*

## Access Modifiers and Packages *(Phạm vi truy cập và Package)*

Packages directly influence Java access levels *(Package ảnh hưởng trực tiếp đến mức độ truy cập dữ liệu trong Java)*:

| Access Modifier *(Từ khóa)* | Same Class *(Cùng lớp)* | Same Package *(Cùng package)* | Subclass (Diff Package) *(Lớp con khác package)* | Different Package *(Khác package hoàn toàn)* |
| :--- | :---: | :---: | :---: | :---: |
| **`private`** | ✅ Yes | ❌ No | ❌ No | ❌ No |
| **`default` (no modifier)** | ✅ Yes | ✅ Yes | ❌ No | ❌ No |
| **`protected`** | ✅ Yes | ✅ Yes | ✅ Yes | ❌ No |
| **`public`** | ✅ Yes | ✅ Yes | ✅ Yes | ✅ Yes |

## Advantages of Packages *(Ưu điểm của Package)*

* **Organize related classes and interfaces.** *(Tổ chức và phân loại các lớp, giao diện có liên quan một cách khoa học.)*
* **Avoid naming conflicts.** *(Tránh xung đột trùng tên lớp — ví dụ có thể có đồng thời `java.util.Date` và `java.sql.Date`.)*
* **Provide access control.** *(Cung cấp cơ chế kiểm soát quyền truy cập thông qua `default` và `protected`.)*
* **Improve code maintainability.** *(Nâng cao khả năng bảo trì mã nguồn.)*
* **Promote code reuse.** *(Thúc đẩy khả năng tái sử dụng code giữa các dự án.)*
* **Make large applications easier to manage.** *(Giúp các dự án quy mô lớn dễ quản lý và phân chia công việc.)*
* **Support modular application design.** *(Hỗ trợ thiết kế ứng dụng theo từng mô-đun độc lập.)*

## Suggested Quiz *(Câu hỏi ôn tập)*

**Question:** What will happen if two classes in different packages have the same name and are imported in a Java file?
*(Điều gì sẽ xảy ra nếu hai lớp ở hai package khác nhau có cùng tên và đều được import tường minh vào cùng một tệp Java?)*

* **A.** Compilation error due to ambiguity. *(Lỗi biên dịch do sự nhập nhằng / không rõ ràng.)*
* **B.** The last imported class is used. *(Lớp được import sau cùng sẽ được sử dụng.)*
* **C.** The first imported class is used. *(Lớp được import đầu tiên sẽ được sử dụng.)*
* **D.** Java automatically renames one class. *(Java tự động đổi tên một lớp.)*

> **Đáp án đúng:** **A (Compilation error due to ambiguity)**
> **Giải thích:** Nếu bạn viết cả `import java.util.Date;` và `import java.sql.Date;` trong cùng một file, trình biên dịch sẽ báo lỗi ngay lập tức vì không biết từ khóa `Date` trong code đang trỏ tới lớp nào. Để dùng cả hai cùng lúc, bạn chỉ import một lớp và lớp còn lại phải viết tên đầy đủ (ví dụ: `java.sql.Date sqlDate = ...`).
