# Object Class in Java *(Lớp `Object` trong Java)*

**Last Updated:** 29 Sep, 2026 *(Cập nhật lần cuối: 29/09/2026)*

The `Object` class is the **root class** of the Java class hierarchy. Every Java class directly or indirectly inherits from the `Object` class.

> **Giải thích:** Lớp `Object` là **lớp gốc (lớp cha cao nhất)** trong toàn bộ hệ thống phân cấp lớp của Java. Mọi lớp trong Java đều trực tiếp hoặc gián tiếp kế thừa từ lớp `Object`.

* **Belongs to the `java.lang` package and is automatically available in every Java program.** *(Thuộc gói `java.lang` và được tự động nạp sẵn trong mọi chương trình Java mà không cần `import`.)*
* **Provides common methods such as `toString()`, `equals()`, `hashCode()`, and `getClass()`.** *(Cung cấp sẵn các phương thức dùng chung cốt lõi như `toString()`, `equals()`, `hashCode()`, và `getClass()`.)*
* **Allows objects of different classes to share a common base type.** *(Cho phép các đối tượng thuộc những lớp khác nhau có thể dùng chung một kiểu dữ liệu cơ sở là `Object`.)*

### Example: Using `toString()` and `hashCode()` *(Ví dụ: Sử dụng `toString()` và `hashCode()`)*

```java
class Person {
    String n;  

    // Constructor
    public Person(String n) {
        this.n = n;
    }

    // Override toString() for a custom string representation
    // (Ghi đè toString() để tùy chỉnh chuỗi đại diện cho đối tượng)
    @Override
    public String toString() {
        return "Person{name:'" + n + "'}";
    }

    public static void main(String[] args) {
        Person p = new Person("Geek");
      
        // Custom string representation (Chuỗi đại diện tùy chỉnh)
        System.out.println(p.toString());
      
        // Default hash code value (Giá trị mã băm mặc định)
        System.out.println(p.hashCode()); 
    }
}
```

**Output *(Kết quả)*:**
```text
Person{name:'Geek'}
321001045
```

**Explanation *(Giải thích)*:** In the above example, we override the `toString()` method to provide a custom string representation of the `Person` class and use the `hashCode()` method to display the default hash code value of the object.
*(Trong ví dụ trên, ta ghi đè phương thức `toString()` để in ra chuỗi mô tả dễ đọc cho lớp `Person` và gọi `hashCode()` để hiển thị giá trị mã băm mặc định của đối tượng).*

## Object Class Methods *(Các phương thức của lớp `Object`)*

The `Object` class provides multiple methods which are as follows *(Lớp `Object` cung cấp các phương thức quan trọng sau)*:

### 1. `toString()` Method *(Phương thức `toString()`)*

`toString()` provides a `String` representation of an object and is used to convert an object to a `String`.
*(Trả về chuỗi `String` đại diện cho một đối tượng và thường được dùng để chuyển đổi thông tin đối tượng thành chuỗi dễ đọc khi in ra console hoặc log).*

```java
class Student {
    String name = "Vishnu";
    int age = 21;

    @Override
    public String toString() {
        return "Student{name='" + name + "', age=" + age + "}";
    }

    public static void main(String[] args) {
        Student s = new Student();
        
        // Calls overridden toString() (Gọi phương thức toString() đã ghi đè)
        System.out.println(s.toString()); 
    }
}
```

**Output *(Kết quả)*:**
```text
Student{name='Vishnu', age=21}
```

**Explanation *(Giải thích)*:** Overridden `toString()` prints a custom readable string for the object. *(Phương thức `toString()` được ghi đè giúp in ra chuỗi thông tin rõ ràng thay vì chuỗi tên lớp + mã hex mặc định).*

---

### 2. `hashCode()` Method *(Phương thức `hashCode()`)*

The `hashCode()` method returns the hash value of an object (not its memory address). It is used heavily in hash-based collections like `HashMap`, `HashSet`, etc.
*(Trả về giá trị mã băm dạng số nguyên của đối tượng — lưu ý đây không phải địa chỉ bộ nhớ thật. Phương thức này được sử dụng cực kỳ phổ biến trong các cấu trúc dữ liệu băm như `HashMap`, `HashSet`).*

```java
class Employee {
    int id = 101;

    @Override
    public int hashCode() {
        return id * 31; // Simple custom hash (Tạo mã băm tùy chỉnh đơn giản)
    }

    public static void main(String[] args) {
        Employee e = new Employee();
        System.out.println(e.hashCode());
    }
}
```

**Output *(Kết quả)*:**
```text
3131
```

**Explanation *(Giải thích)*:** `hashCode()` returns an integer value used in hashing-based collections like `HashMap`. If two objects are equal (according to `equals()`), they must produce the same hash code. *(Nếu hai đối tượng bằng nhau qua `equals()`, chúng bắt buộc phải trả về cùng một giá trị `hashCode()`).*

---

### 3. `equals(Object obj)` Method *(Phương thức `equals(Object obj)`)*

The `equals(Object obj)` method compares the current object with another object for equality. By default, `Object.equals()` compares object references, but it can be overridden to define equality based on object data.
*(So sánh đối tượng hiện tại với một đối tượng khác xem có bằng nhau hay không. Mặc định `Object.equals()` chỉ so sánh địa chỉ tham chiếu giống toán tử `==`, nhưng thường được ghi đè để so sánh nội dung dữ liệu bên trong đối tượng).*

```java
class Book {
    String title;

    Book(String title) { 
        this.title = title; 
    }

    @Override 
    public boolean equals(Object obj) {
        // Same object reference (Cùng trỏ tới một đối tượng trong bộ nhớ)
        if (this == obj) {
            return true;
        }

        // Check for null and incompatible type (Kiểm tra null và khác kiểu dữ liệu)
        if (!(obj instanceof Book)) {
            return false;
        }

        Book b = (Book) obj;
        return this.title.equals(b.title);
    }

    public static void main(String[] args) {
        Book b1 = new Book("Java");
        Book b2 = new Book("Java");

        System.out.println(b1.equals(b2));
    }
}
```

**Output *(Kết quả)*:**
```text
true
```

**Explanation *(Giải thích)*:** The overridden `equals()` method first checks whether both references point to the same object and then verifies that `obj` is a `Book` before casting. It compares the `title` values to determine whether the two `Book` objects are equal.
*(Phương thức `equals()` kiểm tra xem hai biến có cùng trỏ tới một đối tượng không, sau đó kiểm tra `obj` có thuộc kiểu `Book` trước khi ép kiểu và so sánh giá trị thuộc tính `title`).*

### 4. `getClass()` Method *(Phương thức `getClass()`)*

The `getClass()` method returns the `Class` object of `"this"` object and is used to get the actual runtime class of the object.
*(Trả về đối tượng `Class` đại diện cho lớp thực tế của đối tượng tại thời điểm chương trình đang chạy (runtime)).*

```java
public class Geeks {
    public static void main(String[] args) {
        Object o = new String("GeeksForGeeks");
        Class c = o.getClass();
        System.out.println("Class of Object o is: " + c.getName());
    }
}
```

**Output *(Kết quả)*:**
```text
Class of Object o is: java.lang.String
```

**Explanation *(Giải thích)*:** The `getClass()` method is used to print the runtime class of the `o` object. *(Dù biến `o` được khai báo kiểu `Object`, `getClass()` vẫn xác định đúng lớp thực tế lúc chạy của nó là `java.lang.String`).*

---

### 5. `finalize()` Method *(Phương thức `finalize()`)*

The `finalize()` method is invoked by the Garbage Collector just before an object is destroyed. It runs when the object has no remaining references. You can override `finalize()` to release system resources and perform cleanup, **but its use is discouraged (deprecated) in modern Java**.
*(Được bộ thu gom rác (Garbage Collector) gọi ngay trước khi một đối tượng bị hủy khỏi bộ nhớ khi không còn tham chiếu nào trỏ tới nó. Có thể ghi đè để dọn dẹp tài nguyên, **tuy nhiên phương thức này đã bị loại bỏ/khuyến cáo không dùng từ Java 9+**).*

```java
public class Geeks {
    public static void main(String[] args) {
        Geeks t = new Geeks();
        System.out.println(t.hashCode());

        t = null;

        // Calling garbage collector (Gợi ý JVM chạy bộ thu gom rác)
        System.gc();

        System.out.println("end");
    }

    @Override 
    protected void finalize() {
        System.out.println("finalize method called");
    }
}
```

**Output *(Kết quả)*:**
```text
1510467688
end
finalize method called
```

**Explanation *(Giải thích)*:** The `finalize()` method is called just before the object is garbage collected. *(Phương thức `finalize()` được gọi ngay trước khi đối tượng `t` bị dọn dẹp khỏi bộ nhớ).*

### 6. `clone()` Method *(Phương thức `clone()`)*

The `clone()` method creates and returns a new object that is a copy of the current object.
*(Tạo và trả về một đối tượng mới là bản sao của đối tượng hiện tại).*

```java
class Student implements Cloneable {
    int id = 1;
    String name = "Vishnu";

    @Override
    public Object clone() throws CloneNotSupportedException {
        return super.clone(); // Shallow copy (Sao chép nông)
    }

    public static void main(String[] args) throws Exception {
        Student s1 = new Student();
        Student s2 = (Student) s1.clone();

        System.out.println(s1.name); // Vishnu
        System.out.println(s2.name); // Vishnu
    }
}
```

**Output *(Kết quả)*:**
```text
Vishnu
Vishnu
```

**Explanation *(Giải thích)*:** `clone()` creates a copy of the current object (shallow copy by default). The class must implement `Cloneable` or else it throws `CloneNotSupportedException`.
*(`clone()` tạo bản sao nông theo mặc định. Lớp bắt buộc phải triển khai interface đánh dấu `Cloneable`, nếu không sẽ ném ngoại lệ `CloneNotSupportedException`).*

### 7. Concurrency Methods: `wait()`, `notify()`, and `notifyAll()` *(Các phương thức đồng bộ đa luồng)*

The `Object` class provides `wait()`, `notify()`, and `notifyAll()` methods for coordination between threads that use the same object's monitor.
*(Lớp `Object` cung cấp 3 phương thức này để điều phối giao tiếp giữa các luồng (threads) cùng sử dụng khóa monitor của một đối tượng).*

* **`wait()`:** Causes the current thread to wait until it is notified, interrupted, or otherwise resumes according to the method variant used. *(Khiến luồng hiện tại tạm dừng và nhả khóa monitor cho đến khi nhận được thông báo đánh thức hoặc bị ngắt.)*
* **`notify()`:** Wakes up one thread waiting on the same object's monitor. *(Đánh thức một luồng duy nhất đang chờ trên monitor của đối tượng đó.)*
* **`notifyAll()`:** Wakes up all threads waiting on the same object's monitor. *(Đánh thức tất cả các luồng đang chờ trên monitor của đối tượng đó.)*

> **Note *(Lưu ý)*:** These methods must be used while the current thread owns the object's monitor, typically inside a `synchronized` block or method. *(Các phương thức này bắt buộc phải được gọi bên trong khối hoặc phương thức `synchronized`).*

```java
class SharedResource {
    private boolean available = false;

    synchronized void waitForResource() {
        try {
            while (!available) {
                System.out.println(Thread.currentThread().getName() + " is waiting...");
                wait();
            }
            System.out.println(Thread.currentThread().getName() + " resumed.");
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }

    synchronized void makeResourceAvailable() { 
        available = true;
        System.out.println("Resource is available.");

        // Wakes up one waiting thread (Đánh thức 1 luồng đang chờ)
        notify();
    }

    synchronized void wakeAllThreads() {
        // Wakes up all waiting threads (Đánh thức toàn bộ luồng đang chờ)
        notifyAll();
    }
}

public class Geeks {
    public static void main(String[] args) throws InterruptedException {
        SharedResource resource = new SharedResource();

        Thread t1 = new Thread(resource::waitForResource, "Thread-1");
        t1.start();

        // Ensure Thread-1 starts waiting (Đảm bảo Thread-1 đã vào trạng thái chờ)
        Thread.sleep(500);

        resource.makeResourceAvailable();
        t1.join();

        // Demonstrates notifyAll()
        resource.wakeAllThreads();
    }
}
```

**Output *(Kết quả)*:**
```text
Thread-1 is waiting...
Resource is available.
Thread-1 resumed.
```

**Explanation *(Giải thích)*:** `wait()` causes `Thread-1` to wait and releases the object's monitor. The `notify()` method wakes one thread waiting on the same monitor. The `notifyAll()` method wakes all waiting threads; in this example, no threads remain waiting when it is called.
*(`wait()` đưa `Thread-1` vào trạng thái chờ và giải phóng khóa. Sau đó `notify()` đánh thức `Thread-1` tiếp tục chạy).*

## Suggested Quiz *(Câu hỏi ôn tập)*

**Question:** Which of the following statements about the `Object` class in Java is true?
*(Phát biểu nào sau đây về lớp `Object` trong Java là đúng?)*

* **A.** Every Java class extends `Object` class either directly or indirectly. *(Mọi lớp trong Java đều kế thừa lớp `Object` một cách trực tiếp hoặc gián tiếp.)*
* **B.** Only classes without a superclass extend `Object` class. *(Chỉ những lớp không có lớp cha mới kế thừa `Object`.)*
* **C.** The `Object` class cannot be extended. *(Lớp `Object` không thể bị kế thừa.)*
* **D.** `Object` class is an abstract class. *(Lớp `Object` là một lớp trừu tượng.)*

> **Đáp án đúng:** **A**
> **Giải thích:** Trong Java, nếu một lớp không khai báo `extends` lớp nào thì trình biên dịch mặc định cho nó kế thừa trực tiếp `java.lang.Object`. Nếu nó kế thừa một lớp khác thì thông qua chuỗi kế thừa đó nó vẫn gián tiếp kế thừa `Object`. Ngoài ra, `Object` là một lớp cụ thể (concrete class) chứ không phải `abstract class`.
