# Super Keyword in Java *(Từ khóa `super` trong Java)*

**Last Updated:** 29 Sep, 2026 *(Cập nhật lần cuối: 29/09/2026)*

The `super` keyword in Java is used to refer to the **immediate parent class object** in an inheritance hierarchy. It allows a subclass to explicitly access parent class members when they are hidden or overridden. This keyword helps maintain clarity and control while working with inheritance.

> **Giải thích:** Từ khóa `super` trong Java được dùng để tham chiếu đến **đối tượng của lớp cha trực tiếp** trong hệ thống phân cấp kế thừa. Nó cho phép lớp con truy cập tường minh các thành phần của lớp cha khi chúng bị ẩn đi (variable hiding) hoặc bị ghi đè (method overriding), giúp code rõ ràng và dễ kiểm soát hơn khi làm việc với tính kế thừa.

* **Used to call parent class constructors using `super()`.** *(Dùng để gọi constructor của lớp cha thông qua `super()`.)*
* **Helps access parent class methods and variables when overridden or hidden.** *(Giúp truy cập các phương thức và biến của lớp cha khi chúng bị ghi đè hoặc bị che khuất.)*
* **Ensures proper inheritance behavior and code reusability.** *(Đảm bảo hành vi kế thừa chuẩn xác và tăng tính tái sử dụng mã nguồn.)*

### Basic Example *(Ví dụ cơ bản)*

```java
class Person {
    String name = "Geeks";
}

class Student extends Person {
    String name = "Student";

    void display() {
        System.out.println("Child Name: " + this.name);
        System.out.println("Parent Name: " + super.name);
    }

    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}
```

**Output *(Kết quả)*:**
```text
Child Name: Student
Parent Name: Geeks
```

**Explanation *(Giải thích)*:** Here, `this.name` refers to the `name` variable of the current `Student` object, while `super.name` accesses the `name` variable inherited from the parent `Person` class. *(Ở đây, `this.name` trỏ tới biến `name` của đối tượng `Student` hiện tại, trong khi `super.name` truy xuất biến `name` được kế thừa từ lớp cha `Person`.)*

---

## Uses of the `super` Keyword *(Các cách sử dụng từ khóa `super`)*

`super` keywords are mainly used in the following contexts *(Từ khóa `super` chủ yếu được dùng trong 3 ngữ cảnh sau)*:

### 1. Use of `super` with Variables *(Dùng `super` với Biến)*

This scenario occurs when a subclass and its superclass have a variable with the same name. The `super` keyword is used in the subclass to explicitly access the variable defined in the superclass.
*(Trường hợp này xảy ra khi lớp con và lớp cha có biến trùng tên nhau. Từ khóa `super` được dùng bên trong lớp con để truy cập rõ ràng tới biến đã được định nghĩa ở lớp cha.)*

```java
// Base class vehicle (Lớp cơ sở / Lớp cha Vehicle)
class Vehicle {
    int maxSpeed = 120;
}

// Subclass Car extending vehicle (Lớp con Car kế thừa Vehicle)
class Car extends Vehicle {
    int maxSpeed = 180;

    void display() {
        // Print maxSpeed from the vehicle class using super
        // (In ra maxSpeed của lớp cha Vehicle bằng từ khóa super)
        System.out.println("Maximum Speed: " + super.maxSpeed);
    }
}

// Driver Program
class Test {
    public static void main(String[] args) {
        Car small = new Car();
        small.display();
    }
}
```

**Output *(Kết quả)*:**
```text
Maximum Speed: 120
```

**Explanation *(Giải thích)*:** In the above example, both the base class and subclass have a member `maxSpeed`. We could access the `maxSpeed` of the base class in the subclass using the `super` keyword. *(Trong ví dụ trên, cả lớp cha và lớp con đều có thuộc tính `maxSpeed`. Nhờ từ khóa `super`, lớp con có thể truy xuất được giá trị `maxSpeed` của lớp cha thay vì bị biến của chính nó che mất.)*

---

### 2. Use of `super` with Methods *(Dùng `super` với Phương thức)*

This is used when we want to call the parent class method. When a subclass overrides a method of its superclass, `super.methodName()` can be used to explicitly invoke the superclass version of that method.
*(Dùng khi chúng ta muốn gọi phương thức của lớp cha. Khi lớp con ghi đè (override) một phương thức của lớp cha, `super.tenPhuongThuc()` giúp gọi lại phiên bản gốc của phương thức đó ở lớp cha.)*

```java
// Superclass Person (Lớp cha Person)
class Person {
    void message() {
        System.out.println("This is person class\n");
    }
}

// Subclass Student (Lớp con Student)
class Student extends Person {
    void message() {
        System.out.println("This is student class");
    }
    
    // Note that display() is only in Student class
    void display() {
        // Will invoke or call current class message() method
        // (Gọi phương thức message() của chính lớp hiện tại - Student)
        message();

        // Will invoke or call parent class message() method
        // (Gọi phương thức message() của lớp cha - Person)
        super.message();
    }
}

// Driver Program
class Test {
    public static void main(String args[]) {
        Student s = new Student();

        // Calling display() of Student
        s.display();
    }
}
```

**Output *(Kết quả)*:**
```text
This is student class
This is person class
```

**Explanation *(Giải thích)*:** In the above example, if we only call `message()`, the current class `message()` is invoked; but with the use of the `super` keyword, `message()` of the superclass can also be invoked. *(Nếu chỉ gọi `message()`, Java sẽ chạy phiên bản đã ghi đè ở lớp `Student`; nhưng nhờ `super.message()`, ta có thể gọi cả phiên bản gốc ở lớp `Person`.)*

---

### 3. Use of `super` with Constructors *(Dùng `super` với Constructor)*

The `super` keyword can also be used to access the parent class constructor. `super()` can call both parameterized as well as non-parameterized constructors depending on the situation.
*(Từ khóa `super` cũng được dùng để gọi constructor của lớp cha. Tùy trường hợp mà `super()` có thể gọi constructor không tham số hoặc `super(tham_số)` để gọi constructor có tham số của lớp cha. Lưu ý: `super()` phải luôn đặt ở dòng đầu tiên trong constructor của lớp con).*

```java
// Superclass Person (Lớp cha Person)
class Person {
    Person() {
        System.out.println("Person class Constructor");
    }
}

// Subclass Student extending the Person class (Lớp con Student)
class Student extends Person {
    Student() {
        // Invoke or call parent class constructor
        // (Gọi constructor của lớp cha Person)
        super();

        System.out.println("Student class Constructor");
    }
}

// Driver Program
class Test {
    public static void main(String[] args) {
        Student s = new Student();
    }
}
```

**Output *(Kết quả)*:**
```text
Person class Constructor
Student class Constructor
```

**Explanation *(Giải thích)*:** In the above example, we have called the superclass constructor using the keyword `super()` via the subclass constructor. *(Constructor của lớp cha được gọi thông qua `super()` bên trong constructor của lớp con, do đó constructor của `Person` sẽ chạy trước rồi mới đến `Student`.)*

## Bonus Example: How to Modify Parent Method's Result

*(Ví dụ mở rộng: Cách tái sử dụng và biến đổi kết quả từ phương thức của lớp cha)*

```java
class ParentClass {
    public boolean isTrue() { 
        return true; 
    }
}

class ChildClass extends ParentClass {
    @Override
    public boolean isTrue() {
        // Calls parent implementation of isTrue()
        // (Gọi cách cài đặt isTrue() của lớp cha để lấy kết quả gốc)
        boolean parentResult = super.isTrue();
        
        // Negates the parent result (Đảo ngược kết quả của lớp cha)
        return !parentResult;
    }
}

public class Main {
    public static void main(String[] args) {
        ChildClass child = new ChildClass();
        
        // Calls child implementation of isTrue()
        boolean result = child.isTrue();

        System.out.println(result);
    }
}
```

**Output *(Kết quả)*:**
```text
false
```

**Explanation *(Giải thích)*:** In the above example, the child class changes the behavior of the parent class `isTrue()` method. It calls the parent's method using the `super` keyword and negates the result, so the final output is `false`. *(Lớp con thay đổi hành vi của phương thức `isTrue()` bằng cách gọi lại logic gốc của lớp cha qua `super.isTrue()` (trả về `true`), sau đó phủ định lại kết quả đó thành `false`.)*
