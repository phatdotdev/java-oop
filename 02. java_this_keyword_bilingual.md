# Java `this` Keyword *(Từ khóa `this` trong Java)*

**Last Updated:** 29 Sep, 2026 *(Cập nhật lần cuối: 29/09/2026)*

The `this` keyword in Java is a reference variable that refers to the **current object** of a class. It is commonly used to distinguish instance variables from local variables when they have the same name.

> **Giải thích:** Từ khóa `this` trong Java là một biến tham chiếu trỏ tới **đối tượng hiện tại** của một lớp. Nó thường được sử dụng nhất để phân biệt giữa biến thực thể (instance variable / thuộc tính của lớp) và biến cục bộ (local variable / tham số truyền vào) khi chúng có tên trùng nhau.

* **Refers to the current class object.** *(Tham chiếu đến đối tượng hiện tại của lớp.)*
* **Used to access current class instance variables and methods.** *(Dùng để truy cập các biến thực thể và phương thức của đối tượng hiện tại.)*
* **Used to invoke another constructor of the same class using `this()`.** *(Dùng để gọi một constructor khác trong cùng một lớp thông qua cú pháp `this()`.)*

### Basic Example *(Ví dụ cơ bản)*

```java
class Student {
    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    void display() {
        System.out.println("ID: " + this.id);
        System.out.println("Name: " + this.name);
    }

    public static void main(String[] args) {
        Student s = new Student(101, "Geeks");
        s.display();
    }
}
```

**Output *(Kết quả)*:**
```text
ID: 101
Name: Geeks
```

**Explanation *(Giải thích)*:** Here, `this.id` and `this.name` refer to the instance variables of the current `Student` object, while `id` and `name` refer to the constructor parameters. *(Ở đây, `this.id` và `this.name` trỏ tới các thuộc tính của đối tượng `Student` hiện tại, còn `id` và `name` là các tham số được truyền vào constructor.)*

---

## Uses of `this` Keyword in Java *(6 cách sử dụng từ khóa `this` trong Java)*

### 1. To Refer to Current Class Instance Variables *(Tham chiếu đến biến thực thể của lớp hiện tại)*

The `this` keyword is commonly used when a constructor or method parameter has the same name as an instance variable.
*(Từ khóa `this` thường được dùng khi tham số của constructor hoặc phương thức trùng tên với thuộc tính của lớp.)*

```java
class Geeks {
    int a;
    int b;

    // Parameterized constructor (Constructor có tham số)
    Geeks(int a, int b) {
        this.a = a;
        this.b = b;
    }

    void display() {
        // Displaying value of variables a and b (Hiển thị giá trị của a và b)
        System.out.println("a = " + a + "  b = " + b);
    }

    public static void main(String[] args) {
        Geeks object = new Geeks(10, 20);
        object.display();
    }
}
```

**Output *(Kết quả)*:**
```text
a = 10  b = 20
```

**Explanation *(Giải thích)*:** Here, `a` and `b` on the right side refer to constructor parameters, while `this.a` and `this.b` refer to the current object's instance variables. Therefore, `this` removes the ambiguity between the parameters and instance variables. *(Ở đây, `a` và `b` ở vế phải là tham số của constructor, còn `this.a` và `this.b` là thuộc tính của đối tượng hiện tại. Do đó, `this` giúp loại bỏ sự nhập nhằng do trùng tên biến.)*

---

### 2. To Invoke the Current Class Constructor *(Gọi Constructor khác của cùng một lớp)*

The `this()` syntax is used for **constructor chaining**, where one constructor calls another constructor of the same class.
*(Cú pháp `this()` được sử dụng để tạo chuỗi constructor (**constructor chaining**), cho phép một constructor gọi tới một constructor khác trong cùng lớp đó. Lưu ý: `this()` bắt buộc phải nằm ở dòng đầu tiên của constructor).*

```java
class Geeks {
    int a;
    int b;

    // Default constructor (Constructor mặc định)
    Geeks() {
        this(10, 20);
        System.out.println("Inside default constructor \n");
    }

    // Parameterized constructor (Constructor có tham số)
    Geeks(int a, int b) {
        this.a = a;
        this.b = b;
        System.out.println("Inside parameterized constructor");
    }

    public static void main(String[] args) {
        Geeks object = new Geeks();
    }
}
```

**Output *(Kết quả)*:**
```text
Inside parameterized constructor
Inside default constructor 
```

**Explanation *(Giải thích)*:** The default constructor `Geeks()` calls the parameterized constructor using `this(10, 20)`, so the parameterized constructor executes first. After initializing `a` and `b`, control returns to the default constructor, which then prints its own message. *(Constructor mặc định `Geeks()` gọi constructor có tham số thông qua `this(10, 20)`, nên constructor có tham số chạy trước. Sau khi gán xong `a` và `b`, luồng thực thi quay lại constructor mặc định để in ra dòng thông báo của nó.)*

---

### 3. To Return the Current Class Instance *(Trả về đối tượng của lớp hiện tại)*

The `this` keyword can be returned from an instance method to return the current object (useful for method chaining).
*(Từ khóa `this` có thể được trả về từ một phương thức để trả về chính đối tượng hiện tại — thường dùng để viết nối chuỗi phương thức / method chaining).*

```java
class Geeks {
    int a;
    int b;

    // Default constructor
    Geeks() {
        a = 10;
        b = 20;
    }

    // Method that returns current class instance (Phương thức trả về đối tượng hiện tại)
    Geeks get() { 
        return this; 
    }

    // Displaying value of variables a and b
    void display() {
        System.out.println("a = " + a + "  b = " + b);
    }

    public static void main(String[] args) {
        Geeks object = new Geeks();
        object.get().display();
    }
}
```

**Output *(Kết quả)*:**
```text
a = 10  b = 20
```

**Explanation *(Giải thích)*:** The method `get()` returns the current object using `this`, so `object.get()` refers to the same `Geeks` instance created in `main`. Calling `display()` on it prints the values of `a` and `b` that were initialized in the default constructor. *(Phương thức `get()` trả về đối tượng hiện tại bằng `this`, do đó `object.get()` trỏ đến đúng đối tượng `Geeks` đã tạo trong `main`, từ đó có thể gọi tiếp `.display()` ngay phía sau.)*

---

### 4. To Pass the Current Object as a Method Argument *(Truyền đối tượng hiện tại làm tham số cho phương thức)*

The `this` keyword can be passed as an argument to another method.
*(Từ khóa `this` có thể được truyền trực tiếp như một đối số (argument) vào một phương thức khác).*

```java
class Geeks {
    int a;
    int b;

    // Default constructor
    Geeks() {
        a = 10;
        b = 20;
    }

    // Method that receives "this" keyword as parameter
    void display(Geeks obj) {
        System.out.println("a = " + obj.a + "  b = " + obj.b);
    }

    // Method that passes current class instance
    void get() { 
        display(this); 
    }

    public static void main(String[] args) {
        Geeks object = new Geeks();
        object.get();
    }
}
```

**Output *(Kết quả)*:**
```text
a = 10  b = 20
```

**Explanation *(Giải thích)*:** The `get()` method passes `this` to `display(this)`. Thus, the current `Geeks` object is passed to the `display()` method, where its instance variables are accessed through `obj`. *(Phương thức `get()` truyền `this` vào `display(this)`. Nhờ vậy, đối tượng `Geeks` hiện tại được gửi sang `display()` và các thuộc tính của nó được truy xuất thông qua tham số `obj`.)*

---

### 5. To Invoke the Current Class Method *(Gọi phương thức của lớp hiện tại)*

The `this` keyword can be used to explicitly invoke an instance method of the current object.
*(Từ khóa `this` có thể được dùng để gọi tường minh một phương thức khác thuộc cùng đối tượng hiện tại. Nếu bạn không viết `this.`, trình biên dịch Java sẽ tự động ngầm thêm vào).*

```java
class Geeks {

    void display() {
        // Calling function show() (Gọi hàm show() của đối tượng hiện tại)
        this.show();

        System.out.println("Inside display function");
    }

    void show() {
        System.out.println("Inside show function");
    }

    public static void main(String args[]) {
        Geeks g1 = new Geeks();
        g1.display();
    }
}
```

**Output *(Kết quả)*:**
```text
Inside show function
Inside display function
```

**Explanation *(Giải thích)*:** Inside `display()`, `this.show()` calls the `show()` method of the same `Geeks` object before executing the next statement. After `show()` prints its message, control returns to `display()`, which then prints `"Inside display function"`. *(Bên trong `display()`, lệnh `this.show()` gọi phương thức `show()` của cùng đối tượng `Geeks` trước khi chạy câu lệnh tiếp theo.)*

---

### 6. To Pass the Current Object as a Constructor Argument *(Truyền đối tượng hiện tại làm tham số cho Constructor của lớp khác)*

The `this` keyword can be passed to another class's constructor when the current object needs to be provided as an argument.
*(Từ khóa `this` có thể được truyền vào constructor của một lớp khác khi cần cung cấp chính đối tượng hiện tại cho lớp đó xử lý).*

```java
class A {
    B obj;

    // Parameterized constructor with object of B as a parameter
    A(B obj) {
        this.obj = obj;

        // Calling display method of class B
        obj.display();
    }
}

class B {
    int x = 5;

    // Default Constructor that creates an object of A by passing 'this'
    B() { 
        A obj = new A(this); 
    }

    // Method to show value of x
    void display() {
        System.out.println("Value of x in Class B : " + x);
    }

    public static void main(String[] args) {
        B obj = new B();
    }
}
```

**Output *(Kết quả)*:**
```text
Value of x in Class B : 5
```

**Explanation *(Giải thích)*:** In class `B`, the constructor passes `this` to `new A(this)`, sending the current `B` object to class `A`. Class `A` stores this reference and calls `obj.display()`, which prints the value of `x` from the same `B` instance. *(Trong lớp `B`, constructor truyền `this` vào `new A(this)` để gửi đối tượng `B` hiện tại sang cho lớp `A`. Lớp `A` lưu lại tham chiếu này và gọi `obj.display()`, in ra giá trị `x` của chính đối tượng `B` ban đầu.)*
