# Inheritance in Java *(Tính kế thừa trong Java)*

**Last Updated:** 9 Oct, 2026 *(Cập nhật lần cuối: 09/10/2026)*

**Inheritance** in Java is a core OOP concept that allows a class to acquire properties and behaviors from another class. It helps in creating a new class from an existing class, promoting code reusability and better organization.

> **Giải thích:** **Tính kế thừa (Inheritance)** trong Java là một khái niệm cốt lõi của OOP cho phép một lớp (class) tiếp nhận các thuộc tính và hành vi từ một lớp khác. Nó giúp tạo ra một lớp mới dựa trên lớp đã có sẵn, thúc đẩy khả năng tái sử dụng mã nguồn và tổ chức chương trình khoa học hơn.

* **A subclass can reuse the fields and methods of the parent class without rewriting the code.** *(Lớp con có thể tái sử dụng các thuộc tính và phương thức của lớp cha mà không cần viết lại code.)*
* **A subclass can add its own fields and methods or modify existing ones to extend functionality.** *(Lớp con có thể bổ sung thêm các thuộc tính, phương thức riêng hoặc chỉnh sửa (ghi đè) những thành phần sẵn có để mở rộng tính năng.)*

### Basic Example *(Ví dụ cơ bản)*

```java
// Parent class (Lớp cha)
class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

// Child class (Lớp con)
class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }
}

// Child class (Lớp con)
class Cat extends Animal {
    void sound() {
        System.out.println("Cat meows");
    }
}

// Child class (Lớp con)
class Cow extends Animal {
    void sound() {
        System.out.println("Cow moos");
    }
}

// Main class (Lớp chính)
public class Geeks {
    public static void main(String[] args) {
        Animal a;
        a = new Dog();
        a.sound();  

        a = new Cat();
        a.sound(); 

        a = new Cow();
        a.sound();  
    }
}
```

**Output *(Kết quả)*:**
```text
Dog barks
Cat meows
Cow moos
```

**Explanation *(Giải thích)*:**
* `Animal` is the base class. *(`Animal` là lớp cơ sở / lớp cha.)*
* `Dog`, `Cat` and `Cow` are derived classes that extend `Animal` class and provide specific implementations of the `sound()` method. *(`Dog`, `Cat` và `Cow` là các lớp dẫn xuất kế thừa từ `Animal` và cung cấp cách cài đặt cụ thể cho phương thức `sound()`.)*
* The `Geeks` class is the driver class that creates objects and demonstrates runtime polymorphism using method overriding. *(Lớp `Geeks` khởi tạo các đối tượng và minh họa tính đa hình lúc chạy thông qua ghi đè phương thức.)*

> **Note *(Lưu ý)*:** The `sound()` method is an instance method, so it is called using an object reference. Here, `new Dog()` creates a `Dog` object, and its reference is assigned to the `Animal` reference `a`. When `a.sound()` is called, Java executes the overridden `Dog` version of `sound()` at runtime.
> *(Phương thức `sound()` là một instance method nên được gọi thông qua tham chiếu đối tượng. Ở đây, `new Dog()` tạo đối tượng `Dog` và gán tham chiếu vào biến `a` kiểu `Animal`. Khi gọi `a.sound()`, Java sẽ thực thi phiên bản `sound()` đã được ghi đè của `Dog` tại thời điểm chạy).*

## Syntax & Key Terminologies *(Cú pháp & Thuật ngữ quan trọng)*

### Syntax *(Cú pháp)*
```java
class Parent {
    // fields and methods (thuộc tính và phương thức)
}

class Child extends Parent {
    // additional fields and methods (thuộc tính và phương thức bổ sung)
}
```
> **Note *(Lưu ý)*:** In Java, inheritance is implemented using the `extends` keyword. *(Trong Java, kế thừa giữa các lớp được thực hiện bằng từ khóa `extends`.)*

### Key Terminologies in Java Inheritance *(Các thuật ngữ chính)*
* **Class *(Lớp)*:** Blueprint from which objects are created. *(Bản thiết kế/khuôn mẫu dùng để tạo ra các đối tượng.)*
* **Superclass *(Lớp cha)*:** Class whose properties are inherited. *(Lớp có các thuộc tính và phương thức được lớp khác kế thừa.)*
* **Subclass *(Lớp con)*:** Class that inherits another class. *(Lớp đi kế thừa từ một lớp khác.)*
* **`extends` *(Từ khóa kế thừa)*:** Keyword used to inherit a class. *(Từ khóa dùng để khai báo sự kế thừa từ một lớp.)*

## Types of Inheritance in Java *(Các loại kế thừa trong Java)*

It defines the different ways a class can inherit properties and behavior from one or more classes. *(Định nghĩa các cách thức khác nhau mà một lớp có thể kế thừa thuộc tính và hành vi từ một hoặc nhiều lớp khác.)*

### 1. Single Inheritance *(Đơn kế thừa)*
In single inheritance, a subclass is derived from only one superclass. It inherits the properties and behavior of a single-parent class. Sometimes, it is also known as simple inheritance.
*(Trong đơn kế thừa, một lớp con chỉ được dẫn xuất từ duy nhất một lớp cha. Nó kế thừa các thuộc tính và hành vi của một lớp cha đơn lẻ.)*

```java
// Super class (Lớp cha)
class Vehicle {
    Vehicle() {
        System.out.println("This is a Vehicle");
    }
}

// Subclass (Lớp con)
class Car extends Vehicle {
    Car() {
        System.out.println("This Vehicle is Car");
    }
}

public class Test {
    public static void main(String[] args) {
        // Creating object of subclass invokes base class constructor
        // (Tạo đối tượng lớp con sẽ tự động gọi constructor của lớp cha trước)
        Car obj = new Car();
    }
}
```

**Output *(Kết quả)*:**
```text
This is a Vehicle
This Vehicle is Car
```

### 2. Multilevel Inheritance *(Kế thừa nhiều cấp)*
In Multilevel Inheritance, a derived class inherits a base class and also acts as the base class for other classes.
*(Trong kế thừa nhiều cấp, một lớp dẫn xuất kế thừa từ một lớp cơ sở, sau đó chính lớp dẫn xuất này lại đóng vai trò là lớp cơ sở cho một lớp khác tiếp theo — tạo thành chuỗi phân cấp: Ông $\rightarrow$ Cha $\rightarrow$ Con).*

```java
class Vehicle {
    Vehicle() {
        System.out.println("This is a Vehicle");
    }
}

class FourWheeler extends Vehicle {
    FourWheeler() {
        System.out.println("4 Wheeler Vehicles");
    }
}

class Car extends FourWheeler {
    Car() {
        System.out.println("This 4 Wheeler Vehicle is a Car");
    }
}

public class Geeks {
    public static void main(String[] args) {
        Car obj = new Car(); // Triggers all constructors in order (Kích hoạt tất cả constructor theo thứ tự từ trên xuống)
    }
}
```

**Output *(Kết quả)*:**
```text
This is a Vehicle
4 Wheeler Vehicles
This 4 Wheeler Vehicle is a Car
```

### 3. Hierarchical Inheritance *(Kế thừa thứ bậc)*
In hierarchical inheritance, more than one subclass is inherited from a single base class (i.e., more than one derived class is created from a single base class). For example, cars and buses both are vehicles.
*(Trong kế thừa thứ bậc, có nhiều lớp con cùng kế thừa từ một lớp cơ sở duy nhất. Ví dụ: cả ô tô và xe buýt đều là phương tiện giao thông).*

```java
class Vehicle {
    Vehicle() {
        System.out.println("This is a Vehicle");
    }
}

class Car extends Vehicle {
    Car() {
        System.out.println("This Vehicle is Car");
    }
}

class Bus extends Vehicle {
    Bus() {
        System.out.println("This Vehicle is Bus");
    }
}

public class Test {
    public static void main(String[] args) {
        Car obj1 = new Car(); 
        Bus obj2 = new Bus(); 
    }
}
```

**Output *(Kết quả)*:**
```text
This is a Vehicle
This Vehicle is Car
This is a Vehicle
This Vehicle is Bus
```

### 4. Multiple Inheritance Through Interfaces *(Đa kế thừa thông qua Interface)*
Java does not support multiple inheritance of classes, meaning a class cannot extend more than one class. However, Java supports multiple inheritance through interfaces, where a class can implement multiple interfaces and provide implementations for their methods.
*(Java không hỗ trợ đa kế thừa đối với `class`, nghĩa là một lớp không thể `extends` nhiều hơn một lớp cha. Tuy nhiên, Java hỗ trợ đa kế thừa thông qua `interface`, nơi một lớp có thể `implements` nhiều interface cùng lúc).*

> **Note *(Lưu ý)*:** An interface is not a superclass. A Java class can extend only one class but can implement multiple interfaces. *(Interface không phải là một superclass. Một lớp Java chỉ có thể kế thừa 1 class nhưng có thể triển khai nhiều interface).*

```java
interface LandVehicle {
    default void landInfo() {
        System.out.println("This is a LandVehicle");
    }
}

interface WaterVehicle {
    default void waterInfo() {
        System.out.println("This is a WaterVehicle");
    }
}

// Subclass implementing both interfaces (Lớp triển khai cả hai interface)
class AmphibiousVehicle implements LandVehicle, WaterVehicle {
    AmphibiousVehicle() {
        System.out.println("This is an AmphibiousVehicle");
    }
}

public class Test {
    public static void main(String[] args) {
        AmphibiousVehicle obj = new AmphibiousVehicle();
        obj.waterInfo();
        obj.landInfo();
    }
}
```

**Output *(Kết quả)*:**
```text
This is an AmphibiousVehicle
This is a WaterVehicle
This is a LandVehicle
```

### 5. Hybrid Inheritance *(Kế thừa lai)*
Hybrid inheritance is a combination of two or more inheritance patterns. Java does not support hybrid inheritance using classes alone when it would require multiple class inheritance. However, similar structures can be created by combining class inheritance with interface implementation.
*(Kế thừa lai là sự kết hợp của hai hoặc nhiều mô hình kế thừa trên. Java không hỗ trợ kế thừa lai chỉ dùng `class` nếu nó dẫn đến đa kế thừa lớp, nhưng có thể tạo cấu trúc tương tự bằng cách kết hợp `extends` lớp và `implements` interface).*

```java
// Superclass (Lớp cha)
class Vehicle {
    void vehicleType() {
        System.out.println("This is a Vehicle");
    }
}

// Interface for fare (Interface quy định thông tin vé)
interface Fare {
    default void fareInfo() {
        System.out.println("Fare information");
    }
}

// Subclass 1: Single inheritance (Đơn kế thừa)
class Car extends Vehicle {
    void carType() {
        System.out.println("This is a Car");
    }
}

// Subclass 2: Hybrid inheritance (extends class + implements interface)
class Bus extends Vehicle implements Fare {
    void busType() {
        System.out.println("This is a Bus");
    }
}

public class GFG {
    public static void main(String[] args) {
        Car car = new Car();
        car.vehicleType(); // inherited from Vehicle
        car.carType();     // specific to Car

        Bus bus = new Bus();
        bus.vehicleType(); // inherited from Vehicle
        bus.busType();     // specific to Bus
        bus.fareInfo();    // from Fare interface
    }
}
```

**Output *(Kết quả)*:**
```text
This is a Vehicle
This is a Car
This is a Vehicle
This is a Bus
Fare information
```

**Explanation *(Giải thích)*:**
* `Car extends Vehicle` demonstrates single inheritance. *(Minh họa đơn kế thừa.)*
* `Car` and `Bus` extending the same superclass, `Vehicle`, demonstrate hierarchical inheritance. *(Cùng kế thừa `Vehicle` minh họa kế thừa thứ bậc.)*
* `Bus extends Vehicle implements Fare` combines class inheritance with interface implementation. *(Kết hợp kế thừa lớp và triển khai interface.)*
* The overall example illustrates a hybrid inheritance structure. *(Tổng thể ví dụ minh họa cấu trúc kế thừa lai.)*

## Java IS-A Type of Relationship *(Mối quan hệ IS-A trong Java)*

**IS-A** represents an inheritance relationship in Java, meaning *"this object is a type of that object"*.
*(**IS-A** đại diện cho mối quan hệ kế thừa trong Java, mang ý nghĩa "đối tượng này là một loại của đối tượng kia").*

```java
public class SolarSystem {}
public class Earth extends SolarSystem {}
public class Mars extends SolarSystem {}
public class Moon extends Earth {}
```

Based on the above example, in Object-Oriented terms, the following are true *(Dựa trên ví dụ trên, các khẳng định sau là đúng)*:
* `SolarSystem` is the superclass of `Earth` class. *(`SolarSystem` là lớp cha của `Earth`.)*
* `SolarSystem` is the superclass of `Mars` class. *(`SolarSystem` là lớp cha của `Mars`.)*
* `Earth` and `Mars` are subclasses of `SolarSystem` class. *(`Earth` và `Mars` là lớp con của `SolarSystem`.)*
* `Moon` is the subclass of both `Earth` and `SolarSystem` classes. *(`Moon` là lớp con của cả `Earth` và `SolarSystem`.)*

```java
class SolarSystem {}
class Earth extends SolarSystem {}
class Mars extends SolarSystem {}

public class Moon extends Earth {
    public static void main(String args[]) {
        SolarSystem s = new SolarSystem();
        Earth e = new Earth();
        Mars m = new Mars();

        System.out.println(s instanceof SolarSystem);
        System.out.println(e instanceof Earth);
        System.out.println(m instanceof SolarSystem);
    }
}
```

**Output *(Kết quả)*:**
```text
true
true
true
```

## What Can Be Done in a Subclass? *(Lớp con có thể làm gì?)*

In subclasses, we can inherit members as is, replace them, hide them, or supplement them with new members *(Trong lớp con, ta có thể giữ nguyên, thay thế, ẩn đi hoặc bổ sung thêm các thành phần mới)*:
* The inherited fields can be used directly, just like any other fields. *(Sử dụng trực tiếp các thuộc tính được kế thừa như thuộc tính của chính nó.)*
* We can declare new fields in the subclass that are not in the superclass. *(Khai báo thêm các thuộc tính mới mà lớp cha không có.)*
* The inherited methods can be used directly as they are. *(Sử dụng trực tiếp các phương thức được kế thừa.)*
* We can write a new instance method in the subclass that has the same signature as the one in the superclass, thus **overriding** it. *(Viết một phương thức instance mới cùng chữ ký với phương thức ở lớp cha để **ghi đè (override)** nó.)*
* We can write a new `static` method in the subclass that has the same signature as the one in the superclass, thus **hiding** it. *(Viết một phương thức `static` mới cùng chữ ký với phương thức ở lớp cha để **ẩn (hide)** nó.)*
* We can declare new methods in the subclass that are not in the superclass. *(Khai báo thêm các phương thức mới chưa có ở lớp cha.)*
* We can write a subclass constructor that invokes the constructor of the superclass, either implicitly or by using the keyword `super`. *(Viết constructor cho lớp con để gọi constructor của lớp cha một cách ngầm định hoặc tường minh qua từ khóa `super`.)*

## Advantages of Inheritance *(Ưu điểm của Tính kế thừa)*

* **Code Reusability *(Tái sử dụng mã nguồn)*:** Inheritance allows for code reuse and reduces the amount of code that needs to be written. The subclass can reuse the properties and methods of the superclass, reducing duplication of code. *(Giảm lượng code phải viết lại bằng cách cho phép lớp con dùng lại thuộc tính và phương thức của lớp cha, tránh lặp code.)*
* **Abstraction *(Hỗ trợ tính trừu tượng)*:** Inheritance allows for the creation of abstract classes that define a common interface for a group of related classes. This promotes abstraction and encapsulation, making the code easier to maintain and extend. *(Cho phép tạo các lớp trừu tượng định nghĩa khuôn mẫu chung cho một nhóm lớp liên quan, giúp dễ bảo trì và mở rộng.)*
* **Class Hierarchy *(Phân cấp lớp rõ ràng)*:** Inheritance allows for the creation of a class hierarchy, which can be used to model real-world objects and their relationships. *(Tạo hệ thống phân cấp lớp giúp mô hình hóa sát thực tế các đối tượng và mối quan hệ của chúng.)*
* **Polymorphism *(Hỗ trợ tính đa hình)*:** Inheritance allows for polymorphism, which is the ability of an object to take on multiple forms. Subclasses can override the methods of the superclass, which allows them to change their behavior in different ways. *(Cho phép lớp con ghi đè phương thức của lớp cha để thể hiện các hành vi khác nhau tùy ngữ cảnh.)*

## Limitations of Inheritance *(Hạn chế của Tính kế thừa)*

* **Complexity *(Tăng độ phức tạp)*:** Deep inheritance hierarchies can make code difficult to understand and maintain. Keep inheritance hierarchies simple or use composition when appropriate. *(Cây kế thừa quá sâu sẽ làm code khó đọc và khó bảo trì. Nên giữ cấu trúc kế thừa đơn giản hoặc dùng Composition khi phù hợp.)*
* **Tight Coupling *(Sự phụ thuộc chặt chẽ)*:** Changes in a superclass can affect its subclasses. Interfaces or composition can be used to reduce tight coupling where appropriate. *(Mọi thay đổi ở lớp cha đều có thể làm ảnh hưởng hoặc phá vỡ hoạt động của các lớp con. Có thể dùng Interface hoặc Composition để giảm bớt sự phụ thuộc này.)*
