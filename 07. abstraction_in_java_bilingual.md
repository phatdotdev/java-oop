# Abstraction in Java *(Tính trừu tượng trong Java)*

**Last Updated:** 29 Sep, 2026 *(Cập nhật lần cuối: 29/09/2026)*

**Abstraction** in Java is the process of hiding implementation details and exposing only the essential functionality of an object. It focuses on **what** an object does rather than **how** it performs the operation.

> **Giải thích:** **Tính trừu tượng (Abstraction)** trong Java là quá trình ẩn đi các chi tiết cài đặt phức tạp bên trong và chỉ hiển thị những tính năng cốt lõi, cần thiết của đối tượng ra bên ngoài. Nó tập trung vào việc đối tượng **làm được gì** thay vì **làm như thế nào**.

* **Reduces complexity by exposing only the necessary features to the user.** *(Giảm độ phức tạp bằng cách chỉ cung cấp những tính năng cần thiết cho người dùng.)*
* **Achieved primarily using abstract classes and interfaces.** *(Đạt được chủ yếu thông qua các lớp trừu tượng (`abstract class`) và giao diện (`interface`).)*
* **Allows implementation details to change without requiring changes to the code that depends on the abstraction.** *(Cho phép thay đổi cách cài đặt bên trong mà không làm ảnh hưởng hay phải sửa code ở những nơi đang gọi lớp trừu tượng đó.)*

---

## Ways to Achieve Abstraction *(Các cách đạt được Tính trừu tượng)*

Java provides two ways to implement abstraction *(Java cung cấp 2 cách để triển khai tính trừu tượng)*:

1. **Abstract Classes *(Lớp trừu tượng)*:** Partial Abstraction *(Trừu tượng một phần — có thể chứa cả phương thức trừu tượng lẫn phương thức thường).*
2. **Interface *(Giao diện)*:** Provides abstraction for behavior, may contain `default` or `static` methods *(Cung cấp sự trừu tượng hóa về mặt hành vi, có thể chứa phương thức `default` hoặc `static`).*

---

## Real-Life Example of Abstraction *(Ví dụ thực tế về Tính trừu tượng)*

A vehicle is a simple real-life example of abstraction. Different types of vehicles can start in different ways, but the common operation can be defined without exposing its implementation details.
*(Phương tiện giao thông là một ví dụ thực tế đơn giản: các loại xe khác nhau có cơ chế khởi động khác nhau, nhưng thao tác chung `start()` có thể được định nghĩa sẵn mà không cần phơi bày chi tiết động cơ bên trong).*

```java
abstract class Vehicle {
    // Abstract method (Phương thức trừu tượng - không có phần thân)
    abstract void start();
}

// Concrete class (Lớp cụ thể kế thừa lớp trừu tượng)
class Car extends Vehicle {
    @Override 
    void start() {
        System.out.println("Car starts with a key or button.");
    }
}

public class Geeks {
    public static void main(String[] args) {
        Vehicle vehicle = new Car();
        vehicle.start();
    }
}
```

**Output *(Kết quả)*:**
```text
Car starts with a key or button.
```

**Explanation *(Giải thích)*:**
* `Vehicle` is an abstract class that declares the abstract `start()` method. *(`Vehicle` là lớp trừu tượng khai báo phương thức `start()`.)*
* `Car` extends `Vehicle` and provides the implementation of `start()`. *(`Car` kế thừa `Vehicle` và viết phần cài đặt chi tiết cho `start()`.)*
* `Vehicle vehicle = new Car();` allows the program to use the `Vehicle` abstraction while the actual implementation is provided by `Car`. *(Cho phép chương trình thao tác thông qua lớp trừu tượng `Vehicle` trong khi hành vi thực tế do `Car` đảm nhận.)*

## 1. Abstract Class *(Lớp trừu tượng)*

An **abstract class** is a class declared using the `abstract` keyword that cannot be instantiated directly. It can contain both abstract methods (without a body) and concrete methods (with a body), allowing it to provide common functionality while leaving some behavior to subclasses.
*(**Lớp trừu tượng** là lớp được khai báo với từ khóa `abstract` và **không thể khởi tạo đối tượng trực tiếp** bằng từ khóa `new`. Nó có thể chứa cả phương thức trừu tượng (không có thân hàm) và phương thức cụ thể (có thân hàm), giúp cung cấp các tính năng dùng chung đồng thời để lại một số hành vi cho lớp con tự định nghĩa).*

* **Can contain abstract and concrete methods.** *(Có thể chứa cả phương thức trừu tượng và phương thức thông thường.)*
* **Can have constructors, instance variables, and static members.** *(Có thể có constructor, biến thực thể và các thành phần `static`.)*

### Example: Shape *(Ví dụ: Hình học)*

This program demonstrates partial abstraction by defining an abstract class `Shape` that includes abstract methods `area()`, `toString()`, a concrete method `getColor()`, and a constructor.
*(Chương trình minh họa tính trừu tượng một phần thông qua lớp trừu tượng `Shape` gồm các phương thức trừu tượng `area()`, `toString()`, phương thức cụ thể `getColor()` và một constructor).*

```java
abstract class Shape {
    String color;

    // Abstract methods (Các phương thức trừu tượng)
    abstract double area();
    public abstract String toString();

    // Abstract class can have a constructor (Lớp trừu tượng vẫn có thể có constructor)
    public Shape(String color) {
        System.out.println("Shape constructor called");
        this.color = color;
    }

    // Concrete method (Phương thức cụ thể có sẵn phần thân)
    public String getColor() {
        return color;
    }
}

class Circle extends Shape {
    double radius;

    public Circle(String color, double radius) {
        // Calling Shape constructor (Gọi constructor của lớp cha Shape)
        super(color);
        System.out.println("Circle constructor called");
        this.radius = radius;
    }

    @Override 
    double area() {
        return Math.PI * Math.pow(radius, 2);
    }

    @Override 
    public String toString() {
        return "Circle color is " + super.getColor() + " and area is : " + area();
    }
}

class Rectangle extends Shape {
    double length;
    double width;

    public Rectangle(String color, double length, double width) {
        // Calling Shape constructor (Gọi constructor của lớp cha Shape)
        super(color);
        System.out.println("Rectangle constructor called");
        this.length = length;
        this.width = width;
    }

    @Override 
    double area() { 
        return length * width; 
    }

    @Override 
    public String toString() {
        return "Rectangle color is " + super.getColor() + " and area is : " + area();
    }
}

public class Test {
    public static void main(String[] args) {
        Shape s1 = new Circle("Red", 2.2);
        Shape s2 = new Rectangle("Yellow", 2, 4);

        System.out.println(s1.toString());
        System.out.println(s2.toString());
    }
}
```

**Explanation *(Giải thích)*:** In the `Shape` example, `Shape` defines the common `color` property and abstract `area()` method. `Circle` and `Rectangle` extend `Shape` and provide their own implementations of `area()`. The `Shape` reference can refer to different shape objects, hiding their specific implementations.
*(Trong ví dụ trên, `Shape` định nghĩa thuộc tính chung `color` và phương thức trừu tượng `area()`. `Circle` và `Rectangle` kế thừa `Shape` và tự cài đặt công thức tính diện tích riêng. Biến tham chiếu kiểu `Shape` có thể trỏ tới nhiều đối tượng hình học khác nhau mà không cần lộ chi tiết tính toán bên trong).*

## 2. Interface *(Giao diện)*

An **interface** in Java defines a contract that specifies the behavior a class should provide. A class implements an interface and provides implementations for its abstract methods. Interfaces can also contain `default` and `static` methods with implementations.
*(**Interface** trong Java định nghĩa một "bản hợp đồng" quy định các hành vi mà một lớp phải cung cấp. Lớp triển khai interface bắt buộc phải viết mã thực thi cho toàn bộ phương thức trừu tượng của interface đó. Ngoài ra, từ Java 8+, interface cũng có thể chứa phương thức `default` và `static` có sẵn phần thân).*

* **A class uses the `implements` keyword to implement an interface.** *(Một lớp dùng từ khóa `implements` để triển khai interface.)*
* **A class can implement multiple interfaces, supporting multiple inheritance of type.** *(Một lớp có thể triển khai nhiều interface cùng lúc, hỗ trợ đa kế thừa về kiểu dữ liệu.)*

### Example: Shape Interface *(Ví dụ: Interface Shape)*

```java
// Define an interface named Shape (Định nghĩa interface tên Shape)
interface Shape {
    // Abstract method for calculating the area (Mặc định là public abstract)
    double calculateArea(); 
}

// Implement the interface in a class named Circle
class Circle implements Shape {
    private double r;

    public Circle(double r) { 
        this.r = r; 
    }

    // Implementing the abstract method from the Shape interface
    @Override
    public double calculateArea() {
        return Math.PI * r * r;
    }
}

// Implement the interface in a class named Rectangle
class Rectangle implements Shape {
    private double length;
    private double width;

    public Rectangle(double length, double width) {
        this.length = length;
        this.width = width;
    }

    // Implementing the abstract method from the Shape interface
    @Override
    public double calculateArea() { 
        return length * width; 
    }
}

public class Main {
    public static void main(String[] args) {
        // Reference type is the interface (Shape)
        Shape cir = new Circle(5.0);
        Shape rect = new Rectangle(4.0, 6.0);

        // Dynamic method dispatch — decides which method to call at runtime
        System.out.println("Area of Circle: " + cir.calculateArea());
        System.out.println("Area of Rectangle: " + rect.calculateArea());
    }
}
```

**Output *(Kết quả)*:**
```text
Area of Circle: 78.53981633974483
Area of Rectangle: 24.0
```

**Explanation *(Giải thích)*:** In the `Shape` interface example, `Shape` declares the `calculateArea()` method. `Circle` and `Rectangle` implement the interface and provide their own area calculations. The `Shape` references `cir` and `rect` allow the program to use both objects through the same interface type.
*(Trong ví dụ này, interface `Shape` khai báo phương thức `calculateArea()`. `Circle` và `Rectangle` triển khai interface và tự cài đặt cách tính diện tích riêng. Hai biến tham chiếu `cir` và `rect` đều có kiểu `Shape`, cho phép chương trình làm việc với cả hai đối tượng thông qua một giao diện thống nhất).*

## Suggested Quiz *(Câu hỏi ôn tập)*

**Question:** Predict the output of the following program *(Dự đoán kết quả đầu ra của chương trình sau)*:

```java
abstract class demo {
    public int a;
    demo() {
        a = 10;
    }
    abstract public void set();
    abstract final public void get();
}

class Test extends demo {
    public void set(int a) {
        this.a = a;
    }
    final public void get() {
        System.out.println("a = " + a);
    }
    public static void main(String[] args) {
        Test obj = new Test();
        obj.set(20);
        obj.get();
    }
}
```

* **A.** `a = 10`
* **B.** `a = 20`
* **C.** Compilation error *(Lỗi biên dịch)*
* **D.** `a = 30`

> **Đáp án đúng:** **C (Compilation error)**
> **Giải thích chi tiết:** Đoạn code trên gặp **2 lỗi biên dịch** nghiêm trọng:
> 1. Phương thức `get()` ở lớp `demo` khai báo đồng thời `abstract` và `final` (`abstract final public void get();`). Trong Java, `abstract` bắt buộc lớp con phải ghi đè (override), còn `final` lại cấm ghi đè — hai từ khóa này mâu thuẫn hoàn toàn nên trình biên dịch sẽ báo lỗi ngay lập tức.
> 2. Lớp `Test` kế thừa `demo` nhưng lại viết hàm `set(int a)` (nạp chồng - overloading) thay vì cài đặt hàm `set()` không tham số của lớp cha `demo`, trong khi `Test` không được khai báo là `abstract`.
